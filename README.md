#  Blinkit Sales Analysis Dashboard | Excel

## Project Overview
This project presents an interactive Excel dashboard built to analyze Blinkit's sales performance and business operations. The dashboard provides valuable insights into sales trends, outlet performance, customer preferences, and product category contributions through dynamic visualizations and filters.

## Key Features

###  Sales Performance Analysis
- Total Sales Analysis
- Average Sales per Product
- Total Number of Items Sold
- Average Customer Rating

###  Outlet Analysis
- Sales by Outlet Size
- Sales by Outlet Location Tier
- Outlet Type Performance Comparison
- Outlet Establishment Trends

###  Product Analysis
- Sales by Item Type
- Fat Content Analysis (Low Fat vs Regular)
- Category-wise Revenue Contribution
- Top Performing Product Categories

### Interactive Features
- Dynamic Slicers for Filtering
- Interactive Charts and Graphs
- Easy Drill-Down Analysis
- User-Friendly Dashboard Layout

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting
- Data Cleaning and Transformation

## Business Insights
- Identified top-performing product categories.
- Compared sales performance across outlet locations and sizes.
- Analyzed customer purchasing preferences.
- Evaluated the impact of outlet characteristics on sales revenue.

## Project Goal
To transform raw retail sales data into meaningful business insights through an interactive Excel dashboard, enabling data-driven decision-making and performance monitoring.
